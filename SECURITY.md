# Security Policy

## Supported

AARUNO 1.0.x receives fixes for build-breaking and safety-documentation issues.

## Reporting

Open a private security advisory or contact the maintainers. Do not post
mains-voltage or battery-safety exploits publicly before a fix is available.

## Scope

This library cannot fix electrical hazards in software. WiFi examples do not
implement TLS pinning; validate certificates in production firmware.
